💰 Full-Stack Expense Tracker
An end-to-end personal finance web application for visualizing and managing spending habits.

The Expense Tracker is a comprehensive tool designed to help users take control of their financial data. This project demonstrates my proficiency in the MERN stack, implementing secure authentication, and building dynamic dashboards to track complex data trends.

🚀 Key Features

Dynamic Dashboards: Real-time visualization of income, expenses, and overall spending trends.


Full CRUD Functionality: Securely create, read, update, and delete financial transactions with persistent data storage.


Secure Authentication: Implementation of secure user login and data protection protocols.


Refactored Logic: Streamlined backend and frontend code to ensure high performance and maintainability (contributing to a significant reduction in architectural complexity).

🛠️ Tech Stack

Frontend: React.js, Tailwind CSS.


Backend: Node.js, Express.js.


Database: MongoDB.


Tools: Git, GitHub, Vercel.
